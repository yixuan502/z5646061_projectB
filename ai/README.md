# AI workflow evidence

This folder contains the project's factual AI-use audit trail:

- `prompt_log_01_part_b_setup.md` through `prompt_log_08_report_draft.md`
  record the staged requests, proposals, corrections, and validation evidence.
- `AI_NOTES.md` is a factual reflection draft marked for student review; it is not
  the student's final personal reflection.
- `AGENTS.md` at the project root records the actual Codex working instructions.

Claude was not used for this project, so the unchanged starter `CLAUDE.md` was
removed rather than presented as evidence. The empty prompt template was also
removed because the completed prompt logs are the auditable records.
